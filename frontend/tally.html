How to Import in Tally Prime

  1. Download the generated .xml file.
  2. Open Tally Prime and open your company.
  3. Press Alt + O (or click Import on top menu).
  4. Select Transactions.
  5. Select File Format: XML and select the downloaded file.
  6. Press Enter. All Sales, Credit Notes, and GST ledgers are imported instantly.
